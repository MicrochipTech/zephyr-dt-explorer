## 0. What was built

* `tests/ui/conftest.py`: fixtures (`ui_run`, `lab1`, `lab1_leer_copy`, `lab1_e54`, `serve`, `chrome`, `page`, `shot`),
  screenshot list in the pytest terminal summary. `tests/ui/ui_helpers.py`: finds elements by their `id=` prop.
  `tests/ui/_app_main.py`: main file for the NiceGUI user simulation. `tests/ui/_serve.py`: server launcher for the smoke tests.
* No `pytest_plugins` registration and no pytest-asyncio: NiceGUI's `user` fixture plugin needs `main_file = main.py` in the ini
  and async fixtures, so `ui_run(scenario)` runs `nicegui.testing.user_simulation` with `asyncio.run` instead (`pyproject.toml`
  stays at markers only). `conftest.pytest_configure` calls NiceGUI's own `pytest_configure` (session storage in a temp folder,
  so no `.nicegui/` in the repo).
* Simulated tests (marker `ui`, 11): `test_ui_deeplinks.py` (node + macros, unknown node, Pins, Package, Board, Draft, Log, Include),
  `test_ui_configure.py` (Configure... I2C -> pads -> Save -> Draft badge/snippet/Kconfig on a COPY of `_soltest/apps/lab1_leer`
  under %TEMP%; Edit pins... prefill + Cancel on lab1), `test_ui_port.py` (Port to board... lab1 -> `%TEMP%\dtx_lab1_e54`, report
  sections, no Apply; the target is recreated with `west --cmake-only` when missing).
* Smoke tests (marker `smoke`, 4; `slow` on the Verify one): Configure -> Check, Configure -> Check -> Verify (47 s, marked slow),
  Port, board view. Own server on a free port (`_serve.py`, started and stopped by PID with `taskkill /PID /T /F`); 8765/8766 untouched.
  Screenshots in `%TEMP%\dtx_ui_shots` (listed at the end of every smoke run).
* Draft redirection: the lab1_leer copy's CMakeCache still names the original as APPLICATION_SOURCE_DIR, so
  `configure.load_draft/save_draft` are monkeypatched to the copy (simulated tests) or to a scratch folder (`_serve.py`).
  The lab1 tests use an empty scratch store (`apps\lab1\.dt_explorer` of another agent is never read). `_serve.py` also disables
  `remember_folder` (no write to `~/.dt_explorer.json`), and the tests set `DTX_LOG_DIR` to a temp folder.
* The save test also checks that the draft JSON is in the copy and that `_soltest/apps/lab1_leer/.dt_explorer` does not exist.

## 6. Missing element ids / markers (follow-up for the builder; no product code was changed)

Elements found by `id=` today: `cfg-*`, `draft-*`, `port-*`, `log-*`, `port-open`, `legend-btn`. Missing or unusable:

* `port-other`: the `id` prop is not on the native input, so Playwright `#port-other` is not found; the smoke test uses
  `get_by_label("or a build folder path")`. The simulation is unaffected.
* Buttons without id: Cancel of the Configure dialog (found by label "Cancel"), the edit/delete icon buttons of a draft node row,
  Copy/Download in the Port dialog, "Reload", "New build...", "Full build", "Open folder", the Legend entries.
* `cfg-prop-*` exists only for text inputs; the enum selects and boolean switches of the neutral properties (parity, stop-bits,
  hw-flow-control, ...) have no id. The `chosen` / `aliases` selects of the dialog have none either.
* Tabs (Nodes, Include tree, Pins, Package, Board, Draft, Log) have no id; the tests use `&tab=` or click by label (`open_tab`).
* The node tree, the include tree and the pin table have no id (found by kind and content); the package SVG has no id (the board SVGs
  have `data-connector`); the source dialog and the build select have none.
* No NiceGUI markers (`.mark()`) anywhere; the helpers use `id=`. Adding `.mark("<same id>")` next to `id=` would allow `user.find(marker=...)`.
* The Log tab's `ui.log` lines are only readable through the element's children (the test does that).
