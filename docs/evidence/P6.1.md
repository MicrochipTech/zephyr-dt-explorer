## Changes

- `dt_explorer/core/model_host.py` (new): `EdtlibHost.for_zephyr_base(zephyr_base)`, cached per
  python-devicetree `src` dir, guarded by an `RLock`. It imports `devicetree{,._private,.dtlib,.grutils,.edtlib}`
  with `src` first on `sys.path`, keeps the module objects in `host.modules`, then removes every
  `devicetree*` key from `sys.modules` and `src` from `sys.path` (keys that existed before are restored).
  The module `__name__` stays `devicetree.*` while imported, so the logger `devicetree.edtlib` that
  validate.py captures keeps its name. `host.load_edt(pickle_path)` uses an `Unpickler` whose `find_class`
  maps `devicetree*` to the host's modules; `host.edtlib` / `host.dtlib` give the module objects.
- `dt_explorer/core/build.py`: the 4 lines (`sys.path` insert + `pickle.load`) became
  `self.edt = EdtlibHost.for_zephyr_base(self.zephyr_base).load_edt(zdir / "edt.pickle")`, plus the one
  import line `from .model_host import EdtlibHost`. The now unused `pickle`/`sys` imports were left alone.
- `dt_explorer/core/validate.py` (permitted exception, ONLY the lookup): `_edtlib(zephyr_base)` now returns
  `host.dtlib, host.edtlib` from the host instead of inserting into `sys.path` and `from devicetree import ...`;
  plus the import line `from .model_host import EdtlibHost`. Without it validate would have used the wrong
  edtlib for a main build (or failed, as no `devicetree` is on `sys.path` any more).
- `tests/test_model_host.py` (new).
