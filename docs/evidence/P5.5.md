# P5.5 evidence: Acceptance, RTOS4 labs to sam_e54_xpro

**Not tested on hardware (HC-4).** Acceptance rests on build evidence only: port, apply to copies, `west build -b sam_e54_xpro`,
and the `__device_dts_ord_*` symbols in the linked image. Nothing was flashed or run on a board.

Environment: `DTX_RTOS4_WS=C:\Masters\26020_RTOS4\zephyrproject` (Zephyr v4.3.0, old `atmel` port for `same54_xpro`, new g1 port
for `sam_e54_xpro`, same workspace for source and target), Zephyr SDK 0.17.4. Product code unchanged. Throwaway scripts live in
`%TEMP%\dtx_p55` (pasted below). Real apps `apps\lab0..lab3` were never written to (section 6).

"emitted" is 0 everywhere: the only node the tool can translate in this target workspace is sercom2 (UART), and the target board
already configures it identically. SPI and I2C have no `microchip,sercom-g1-*` binding or driver in Zephyr v4.3.0 of the RTOS4
workspace (the port report says: present from 4.5 on), so they are `no_target`. (P5.6 had sercom4/sercom7 emitted because its
target came from a newer workspace; here, as the card says, the target is the same workspace.)

Result: lab0, lab1, lab2 build and link with plain `west build -b sam_e54_xpro` on the copies; lab1 links and `my_led0` is in the
image. lab3 does not build; cause attributed below (tool limitation: the I2C sensor bus has no target driver in this workspace;
not an app, layout or apply defect).

## 2. Script (`%TEMP%\dtx_p55\p55.py`, port + apply on the copy)

```python
import sys, os, collections
from pathlib import Path
sys.path.insert(0, r"C:\Masters\dt_explorer")
from dt_explorer.app import load_plugins; load_plugins()
from dt_explorer.core.port_report import port_build
from dt_explorer.core import apply as ap
n = sys.argv[1]
ws = Path(r"C:\Masters\26020_RTOS4\zephyrproject"); tmp = Path(os.environ["TEMP"])
src = ws/"apps"/f"lab{n}"/"build_same54_xpro"; tgt = tmp/f"dtx_p55_tgt_lab{n}"
copy = tmp/"dtx_p55"/"apps"/f"lab{n}"
res = port_build(src, tgt)
rep = res.report
print("=== report ===")
print("\n".join(rep.lines()))
print("\n=== overlay ===\n"+res.overlay)
print("=== conf ===\n"+res.conf)
cnt = collections.Counter(x.status for x in rep.nodes)
print("NODECOUNTS", dict(cnt), "carried", len(rep.carried), "not_carried", len(rep.not_carried))
bt, single = ap.target_of(tgt)
print("target board target:", bt, "single SoC:", single)
plan = ap.plan_apply(copy, bt, res.overlay, res.conf, single_soc=single, source_board=ap.target_of(src)[0])
print("\n".join(ap.plan_lines(plan)))
r = ap.apply(plan)
print("written:", [str(x) for x in r.written]); print("skipped:", [str(x) for x in r.skipped]); print("refused:", [str(x) for x in r.refused])
```
