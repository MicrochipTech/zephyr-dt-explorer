## Conflicts met and what the port said (section 7)

* blinky_pwm run 1, `tcc1` WO0 = PB18: the SG41 board enables `&tcc1` as `microchip,tcc-g1-counter`; port status `conflict`, not emitted, with the
  suggestion "choose instance and pads with Configure...". Re-chosen: `tcc3`.
* bme280 run 1, `sercom1` PC22/PC23: those are the GMAC MDIO pads on the SG41 board (`&mdio`); port `conflict` for `sercom1`, and `bme280_76` listed as
  not carried because its bus is not ported. Re-chosen: `sercom5` on PA23/PA22.
* In every run, the SAME54 board's own sercom2/4/7 conflict with the SG41 board's sercom4 console / sercom0 / sercom6 and are not emitted (board nodes, not part of this scenario).

## Tool bugs and limitations (precise; product code not touched)

* **B1 (bug) a chosen PWM prescaler is silently replaced by 8.** `core/render.py::_render_one` does `props.update(recipe.default_props(node.compatible))`
  (default prescaler 8) for every new node and then skips every `vendor_props` key that is already in `props` (`derived = set(props)`). A prescaler set via
  `rec.default_props(compat, prescaler=1)` / `node.vendor_props` is therefore dropped: `suggest_prescaler(120 MHz, 20 ms, 24 bit)` gives 1, the overlay says
  `prescaler = <8>` (same with 2). Reproduced with 1 and 2 on `tcc1`/`tcc3`. P8.8's evidence shows the chosen values (`<256>` for tc2), so this came with the
  P8.19b `default_props` change. The g1 ADC `prescaler` (required) passes the same code path and was not re-tested here.
* **B2 (limitation/bug) Board nodes cannot point a PWM LED at a controller that the draft itself enables.** `board_nodes.pwm_controllers(model)`
  offers only controllers that are `okay` in the build (`tcc0`); `check_spec` reports `error: pwm_led_tool: no PWM controller 'tcc3' in the build`
  (section 6, blinky_pwm). The entry was written through `apply_spec` (bypassing `check_spec`), which renders and verifies fine. In the UI the scenario "new TCC + PWM LED on it" is blocked.
* **B3 (bug) the port does not understand the tool's own `&{/} { ... }` Board-nodes output.** Section 5b of the blinky_pwm port: `not carried: & (node, ...same54_xpro.overlay:19): label  is not in the source devicetree`
  and `a named node block outside / and &label is not carried over`; section 5 lists `/user_pwm_leds pwm-leds [overlay] ... (NOT in the target)`. Consequence: the new PWM LED and the `pwm-led0` alias
  are not carried to the SG41, which keeps the board's `pwm_led0` on tcc0.
* **L1** see hand additions (`zephyr,user` / `io-channels`).
* **L2 (surprise, by design) the port covers the whole board, not only the nodes the user added.** Every run emits `tcc0` with a pad override to the SAME54 pads
  (`tcc0_pwm_edit` = PC18 WO2, "the target board puts this node on other pads; the overlay overrides them"), `gmac` `phy-handle`, `mdio` pads (PC11/PC12 instead of the SG41 board's) and a conf block with
  `CONFIG_NETWORKING`, `NET_L2_ETHERNET`, `ETH_*`: a PWM blinky on the SG41 becomes an 88 KB Ethernet image, and the SG41 board's own tcc0/mdio pad choices are replaced by the SAME54 board's.
  For adc_dt the `&adc1` pad override replaces the SG41 board's adc1 pads by PB04/PB05 (`adc1_adc_edit`).
* **L3 (not emitted) clock setup.** For tcc3 and sercom5 the report says `Add in the target board file: &clock { gclkperiph { tcc3 {...}; }; mclkperiph {...}; }`; the overlay does not contain it.
  The images link; whether the peripherals get a clock on the SG41 was not checked (no hardware, HC-4).
* **L4 (note)** `pwm_led_tool` has no `__device_dts_ord_*` of its own (the pwm-leds container carries the device); the nm rows for pwm LED children say "False" and are not a failure.
* Console encoding: scripts that print the report need `PYTHONIOENCODING=utf-8` (the report contains an arrow character); with the default cp1252 the print raises `UnicodeEncodeError`. Not a tool defect, noted for repeatability.

### common.py

```python
import sys, os, re, subprocess
from pathlib import Path
sys.path.insert(0, r"C:\Masters\dt_explorer")
from dt_explorer.app import load_plugins; load_plugins()
from dt_explorer.core import verify, apply as ap
from dt_explorer.core.build import BuildModel
from dt_explorer.ui import configure as C
from dt_explorer.ui.draft_tab import kconfig_lines
T = Path(os.environ["TEMP"]) / "dtx_p818"

def show(findings):
    print("--- validate findings (%d) ---" % len(findings))
    for f in findings: print(f.severity, f.kind, f.node, f.message)
    errs = [f for f in findings if f.severity == "error"]
    print("errors:", errs); return errs

def do_verify(build, overlay, conf, tag):
    res = verify.verify(build, overlay, conf, on_line=None, scratch_root=T / ("verify_" + tag), timeout=900)
    print("--- Verify with west (%s) ---" % tag)
    print("rc:", res.returncode, "ok:", res.ok, "duration: %.1f s" % res.duration)
    print("errors:", res.errors); print("warnings:", res.warnings)
    print("cmd:", " ".join(res.cmd)); print("log tail:\n" + "\n".join(res.log_tail[-6:]))
    return res

def apply_to(build, app, overlay, conf):
    plan = ap.draft_plan(build, overlay, conf, app_dir=app)
    print("\n".join(ap.plan_lines(plan)))
    r = ap.apply(plan, append={"overlay", "conf"})
    print("written:", [str(x) for x in r.written], "skipped:", [str(x) for x in r.skipped], "refused:", [str(x) for x in r.refused])
    print("next:", "\n".join(ap.next_step_lines(plan)))
    return r

def port_apply(src_build, tgt_build, app):
    from dt_explorer.core.port_report import port_build
    res = port_build(src_build, tgt_build)
    rep = res.report
    print("=== report ==="); print("\n".join(rep.lines()))
    print("\n=== overlay ===\n" + res.overlay); print("=== conf ===\n" + res.conf)
    import collections
    print("NODECOUNTS", dict(collections.Counter(x.status for x in rep.nodes)), "carried", len(rep.carried), "not_carried", len(rep.not_carried))
    bt, single = ap.target_of(tgt_build)
    plan = ap.plan_apply(app, bt, res.overlay, res.conf, single_soc=single, source_board=ap.target_of(src_build)[0])
    print("\n".join(ap.plan_lines(plan)))
    r = ap.apply(plan, append={"overlay", "conf"})
    print("written:", [str(x) for x in r.written], "skipped:", [str(x) for x in r.skipped], "refused:", [str(x) for x in r.refused])
    return res
```

```python
from common import *
from dt_explorer.core import plugins, board_nodes as B
from dt_explorer.recipes import pwm_tc_tcc as P
build = T/"tgt_same54_blinky_pwm"; app = T/"same54"/"blinky_pwm"
PADS = {"WO0": os.environ.get("PWM_PAD", "PB18")}; LAB = os.environ.get("PWM_TCC", "tcc1")
m = BuildModel(build); s = C.ConfigSession(m); used = s.used_by()

n = s.node_for_label(LAB); inst = s.instance_of(n)

opt = C.ClassOption("pwm", compat, rec); roles = C.option_roles(opt, inst)
props, problem = C.derive_props(opt, inst, PADS, roles); print("pads", PADS, "derived", props, "problem", problem)
node = C.build_node(option=opt, instance=inst, label=LAB, pins=PADS, roles_order=roles)

node.vendor_props = rec.default_props(compat, inst.name, prescaler=presc)
s.upsert(node)
# Board nodes: PWM LED + alias pwm-led0 (core API of ui/board_nodes dialog)
spec = B.BoardSpec(entries=[B.Entry(kind=B.PWM_LEDS, name="pwm_led_tool", ctrl=LAB, channel=0, period_ns=20_000_000)],
                   aliases={"pwm-led0": "/user_pwm_leds/pwm_led_tool"})
pwm = B.pwm_controllers(m); print("pwm controllers the dialog offers:", [p["label"] for p in pwm])
probs = B.check_spec(spec, model=m, pad_map=s.gpio_map(), pwm_ctrls={p["label"]: p for p in pwm},
                     existing_aliases={a for a in m.edt._dt.alias2node})
print("check_spec problems:", [str(p) for p in probs])
B.apply_spec(s.draft, spec, s.gpio_map(), {LAB: 2})
overlay = s.overlay(); print("\n--- overlay ---\n" + overlay)
show(s.check())
conf = "\n".join(kconfig_lines(s.kconfig())) + "\n"; print("--- conf ---\n" + conf)
r = do_verify(build, overlay, conf, "pwm")
if r.returncode == 0 and os.environ.get("APPLY"):
    apply_to(build, app, overlay, conf)
```
