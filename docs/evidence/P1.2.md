## Design gaps filled
- API_VERSION = 1; a plugin is compatible iff its api_version == 1 (design silent on comparison rule).
- Board reader (`extensions`, `read(path)`), connector type (`pin_roles()`, `detect(pins)`, `zephyr_binding`) and translation (`source`, `target`, `translate(props)`) method names are not given in the design; minimal choices.
- Protocol signatures for formatter/recipe: argument and return types chosen minimally (design names only the methods).
- `BuildInfo`/`BoardNetlist` are TYPE_CHECKING aliases (Any); core/buildinfo.py is written by another card.
- Decorators accept a class (instantiated with no args) or an instance; registry keyed by plugin name, translations by (source, target).
- Plugins that fail to load from entry points are logged and skipped.
