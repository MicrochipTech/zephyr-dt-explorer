## Valid-combination tables and sources

Sources: ATDF `ATSAME54P20A.atdf` value groups `SERCOM_USART_CTRLA__TXPO/RXPO`, `SERCOM_SPIM_CTRLA__DOPO/DIPO` (hal_microchip packs, sam_d5x_e5x/atsame54/atdf); `dts/bindings/serial/atmel,sam0-uart.yaml` (SAMD5/E5 table). The `atmel,sam0-spi.yaml` binding gives no table (dipo/dopo only "Data In/Out Pinout"), so SPI comes from the ATDF only.

| Class | Property | Meaning | Roles |
|---|---|---|---|
| UART | txpo 0 | | TX PAD0 (PAD1 = XCK, unused async) |
| UART | txpo 1 | reserved on D5x/E5x | rejected |
| UART | txpo 2 | | TX PAD0, RTS PAD2, CTS PAD3 |
| UART | txpo 3 | | TX PAD0, RTS (TE) PAD2, no CTS |
| UART | rxpo n | | RX PADn, n in 0..3, must differ from the TX/RTS/CTS pads |
| SPI | dopo 0 | | MOSI PAD0, SCK PAD1, hardware SS PAD2 |
| SPI | dopo 2 | | MOSI PAD3, SCK PAD1, hardware SS PAD2 |
| SPI | dopo 1, 3 | not offered by ATDF for E5x | rejected |
| SPI | dipo n | | MISO PADn, not MOSI/SCK pad, not PAD2 when CS is used |
| I2C | none | fixed | SDA PAD0, SCL PAD1 |

Valid combinations: UART 6 (txpo0 x rx{1,2,3}, txpo3 x rx{1,3}, txpo2 x rx{1}), SPI 6 (dopo0 and dopo2, each: MISO two pads without CS, one with CS), I2C 1.
Design decisions: roles RTS/CTS and CS are optional; CTS without RTS is rejected. Kconfig symbols verified in drivers/serial/Kconfig.sam0 (UART_SAM0), drivers/i2c/Kconfig.sam0 (I2C_SAM0), drivers/spi/Kconfig.sam0 (SPI_SAM0); parents SERIAL, I2C, SPI are the menuconfigs in drivers/*/Kconfig.
