# P2.3 evidence: vendor defaults from the providers

Worktree `agent-a9946282df34643d1` was reset with `git reset --hard master` (master at `220200d`) before
work started. `dt_explorer/core/west_tools.py` and `dt_explorer/ui/new_build.py` exist afterwards.

## What changed

- `core/west_tools.py`: `DEFAULT_VENDORS` removed. `list_boards(ws, vendors=None, extra_board_dirs=())`:
  `vendors=None` means every vendor, the generic core behaviour.
- `core/plugins.py`: `board_vendors` documented as an optional provider attribute (not a required protocol
  member, so existing providers stay valid); new helper `board_vendors()` returns the sorted, lower-cased
  union over `providers()` as a tuple, empty when none declares it.
- `providers/microchip_atdf.py`: `board_vendors = ("atmel", "microchip")`.
- `ui/new_build.py`: the dialog calls `list_boards(ws, vendors=plugins.board_vendors() or None)`. With no
  declaring provider it shows all vendors. The hardcoded "Microchip/Atmel" label text is now built from the
  provider vendors: `Board (<n> Atmel/Microchip)` with the providers loaded.
- `tests/test_west_tools.py`: synthetic test passes `vendors=("microchip",)` explicitly; new tests for
  `vendors=None`/`()`, the RTOS4 27-entry count through `load_plugins()` and `board_vendors()`, and the
  sorted union (registry snapshot restored afterwards).

## Acceptance 1: board list with providers loaded, and all vendors

```

from dt_explorer.app import load_plugins
from dt_explorer.core import plugins, west_tools as wt
load_plugins()
```
